# Набор проверок

Команды выполняются из каталога examples. bash setup.sh запускает локальные зависимости. bash verify.sh передаёт настройки каждому модулю и выполняет тесты с реальными PostgreSQL и Kafka. Модули показывают отдельные уровни проверки. При использовании уже запущенных зависимостей адреса передаются переменными AUDIT_TEST_REQUESTS_DSN, AUDIT_TEST_CHECKS_DSN, AUDIT_TEST_REPORTS_DSN и AUDIT_TEST_BROKERS.

Файл wait-example_test.go.txt относится к самостоятельной работе. Он содержит слишком короткое фиксированное ожидание и в основной набор не включён.
