# Проверка совместимости

Из каталога example выполняется команда go test -v ./.... TestEventVersionMatrix проверяет содержимое и готовность отчёта для обеих версий событий и консьюмеров. TestDecodedButIncompatible отделяет декодирование от совместимости смысла. TestProtobufVersionMatrix проверяет двоичный обмен сообщениями старой и новой схемы через частные дескрипторы. Это проверка формата сообщений без запуска транспорта.
